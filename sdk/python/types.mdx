## SessionBlock

One block in a [debugger](/debugger/introduction) session, as returned by `client.rollout_sessions.list_blocks(...)`.

```python
SessionBlockType = Literal["trace", "evaluation", "text"]

class TraceBlockContent(TypedDict, total=False):
    traceId: str
    note: Optional[str]

class EvaluationBlockContent(TypedDict, total=False):
    evaluationId: str
    note: Optional[str]

class TextBlockContent(TypedDict):
    text: str

SessionBlockContent = Union[TraceBlockContent, EvaluationBlockContent, TextBlockContent]

class SessionBlock(TypedDict):
    id: str
    createdAt: str  # ISO-8601
    type: str  # one of SessionBlockType for known blocks
    content: dict[str, Any]  # narrow with the *BlockContent shapes
```

## DebugContext

Debugger coordinates carried on a `LaminarSpanContext` so a downstream service joins the same debug session and replay window.

```python
class DebugContext(BaseModel):
    enabled: bool
    session_id: str | None
    replay_trace_id: str | None
    cache_until: str | None
```

## Version Helpers

```python
get_latest_pypi_version() -> str
is_latest_version() -> bool
```

- `get_latest_pypi_version()` returns `__version__` on failure.
- `is_latest_version()` returns `True` on failure.
